# How much memory?
- a bit is a binary digit that can have the value 0 or 1.
- A nibble is half a byte, or 4 bits.
- A byte is defined as 8 bits.
- A word is two bytes, or 16 bits.
- A kilobyte (KB) is 2^10 bytes, which is 1024 bytes. 
- A megabyte (MB) is 2^20 bytes or 1024 KB.
- A gigabyte (GB) is 2^30 bytes or 1024 MB . 
- A terabyte (TB) is 2^40 bytes or 1024 GB.

# Two main types of memory

## ROM
(Read Only Memory) :

- Non-Volatile
- Contains data and programs thats essential for operation .
